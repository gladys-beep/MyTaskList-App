## Deskripsi Aplikasi
MyTaskList adalah aplikasi manajemen tugas berbasis mobile yang dibuat menggunakan React Native dan Expo. Aplikasi ini membantu pengguna menambahkan, mengatur prioritas, menyelesaikan, dan menghapus tugas sehari-hari agar aktivitas lebih terorganisir.

## Fitur yang Diimplementasikan
- [x] Menambahkan tugas baru.
- [x] Validasi input tugas agar tidak kosong.
- [x] Menentukan prioritas tugas (Tinggi, Sedang, Rendah).
- [x] Menampilkan daftar tugas menggunakan FlatList.
- [x] Menandai tugas sebagai selesai.
- [x] Menghapus tugas.
- [x] Filter tugas (Semua, Aktif, Selesai).
- [x] Menampilkan jumlah tugas yang telah selesai.

## Cara Menjalankan Project

1. Clone repository:

   ```bash
   git clone https://github.com/gladys-beep/MyTaskList-App.git
   ```

2. Masuk ke folder project:

   ```bash
   cd MyTaskList-App
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Jalankan aplikasi:

   ```bash
   npx expo start
   ```

5. Scan QR Code menggunakan aplikasi Expo Go pada HP.
